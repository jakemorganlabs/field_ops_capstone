# Code Reference for LED Troffer Retrofit in WA

This code reference applies to led troffer retrofit installations in Seattle, WA. It summarizes the governing requirements for estimating and installation. Synthetic summary for testing only.

## Governing Codes

Code requirements covered: Title 24 compliance, recycling old lamps. WA code reference.

- Washington State Energy Code C405 and California Title 24 Part 6 lighting controls
- EPA Universal Waste Rule 40 CFR 273

## Requirements

- Title 24 compliance and the Washington State Energy Code both require occupancy sensor control that reduces lighting power by at least 50 percent in unoccupied spaces.
- Daylight zones within 15 feet of windows must have automatic daylight-responsive controls.
- Recycling old lamps is mandatory: fluorescent lamps contain mercury and must be handled as universal waste with a recycling manifest.
- Replacement LED troffers must be listed and installed with the manufacturer's dimming driver.
- Lighting power density after retrofit must not exceed 0.65 W per square foot for office space.
- Existing ballasts must be removed and PCB-containing ballasts recycled separately.

## Labor Guidance

- Work must be performed by a licensed contractor with a permit and final inspection.
- Inspection and documentation time should be estimated at 5 percent of installation labor.
