# Structured Cabling Proposal

## Project Summary

Synthetic proposal for a structured cabling system in Philadelphia, PA.

## Scope

Install 200 Cat6A data drops with patch panels, racks, and cable management.

## Materials

- Cat6A plenum cable, 1000 ft box: $195.00 per box. Need 10 boxes.
- Cat6A keystone jack: $8.75 each. Need 200 jacks.
- 2-port wall plate: $4.25 each. Need 100 plates.
- 48-port patch panel: $185.00 each. Need 5 panels.
- 7-foot equipment rack: $485.00 each. Need 2 racks.
- Horizontal cable manager, 1 RU: $24.00 each. Need 20 managers.
- Velcro cable tie, 100-pack: $12.00 per pack. Need 5 packs.

## Labor

- Electrician: 1 hour per drop at $79.00 per hour.
- Apprentice: 0.5 hours per drop at $37.00 per hour.
