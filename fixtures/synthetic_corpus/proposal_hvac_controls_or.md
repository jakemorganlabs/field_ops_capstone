# HVAC Controls Upgrade Proposal

## Project Summary

Synthetic proposal for an HVAC controls upgrade in Portland, OR.

## Scope

Install a new building automation system controller and 20 VAV box controllers.

## Materials

- BACnet building controller: $4,800.00 each. Need 1 controller.
- VAV box controller with actuator: $685.00 each. Need 20 controllers.
- Temperature sensor, wall mount: $45.00 each. Need 20 sensors.
- CO2 sensor, duct mount: $125.00 each. Need 10 sensors.
- 22 AWG twisted pair cable, 1000 ft spool: $95.00 per spool. Need 3 spools.
- Control enclosure, 16x20x8: $185.00 each. Need 2 enclosures.

## Labor

- Controls technician: 4 hours per controller at $90.00 per hour.
- Electrician: 2 hours per controller at $80.00 per hour.
