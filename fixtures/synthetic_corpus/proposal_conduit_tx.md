# Commercial Conduit Run Proposal

## Project Summary

Synthetic proposal for a commercial conduit run in Austin, TX.

## Scope

Install 2,000 linear feet of 3/4 inch EMT conduit with associated boxes and fittings.

## Materials

- 3/4 inch EMT conduit, 10 ft stick: $14.50 each. Need 200 sticks.
- 3/4 inch EMT connector, set screw: $0.85 each. Need 400 connectors.
- 3/4 inch EMT coupling: $0.75 each. Need 200 couplings.
- 4-inch square box, deep: $4.20 each. Need 40 boxes.
- Single-gang device box: $2.10 each. Need 80 boxes.
- Wire nut, 100-pack: $8.50 per pack. Need 5 packs.
- Grounding bushing, 3/4 inch: $2.40 each. Need 40 bushings.

## Labor

- Electrician: 0.25 hours per stick at $75.00 per hour.
- Apprentice: 0.15 hours per stick at $35.00 per hour.
