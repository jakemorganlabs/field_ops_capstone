# Access Control System Proposal

## Project Summary

Synthetic proposal for an access control system in Chicago, IL.

## Scope

Install 16 card reader doors with electrified strikes and a central panel.

## Materials

- HID card reader, multi-class: $245.00 each. Need 16 readers.
- Electrified strike, fail secure: $185.00 each. Need 16 strikes.
- Door position sensor: $24.00 each. Need 16 sensors.
- Request-to-exit sensor: $65.00 each. Need 16 sensors.
- Access control panel, 32 door: $2,400.00 each. Need 1 panel.
- 18 AWG stranded cable, 1000 ft spool: $125.00 per spool. Need 2 spools.

## Labor

- Low voltage technician: 2 hours per door at $74.00 per hour.
- Apprentice: 1 hour per door at $36.00 per hour.
