# Code Reference for IP Video Surveillance in MI

This code reference applies to ip video surveillance installations in Detroit, MI. It summarizes the governing requirements for estimating and installation. Synthetic summary for testing only.

## Governing Codes

Code requirements covered: NEC Article 725, cybersecurity requirements. MI code reference.

- NEC Article 725 Class 2 and Class 3 Remote-Control, Signaling, and Power-Limited Circuits
- NIST SP 800-53 and CISA cybersecurity requirements for networked video

## Requirements

- PoE camera circuits are Class 2 power-limited circuits under NEC Article 725 and must be separated from power conductors.
- Cybersecurity requirements: default camera passwords must be changed, firmware updated, and the video VLAN isolated from the corporate network.
- Cat6 cable runs to IP cameras must not exceed 328 feet including patch cords.
- The NVR must retain 30 days of recording at the configured frame rate.
- Exterior cameras require a listed junction box and a drip loop at the cable entry.
- Camera placement must comply with state privacy law; no coverage of restrooms or changing areas.
