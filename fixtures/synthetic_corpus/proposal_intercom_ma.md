# Intercom System Proposal

## Project Summary

Synthetic proposal for an IP intercom system in Boston, MA.

## Scope

Install 12 IP intercom master stations and 48 substations across a campus.

## Materials

- IP intercom master station: $685.00 each. Need 12 masters.
- IP intercom substation: $245.00 each. Need 48 substations.
- PoE injector, 30 W: $45.00 each. Need 12 injectors.
- Network switch, 48 port: $1,250.00 each. Need 1 switch.
- Cat6 cable, 1000 ft box: $165.00 per box. Need 4 boxes.
- Surface back box: $12.00 each. Need 60 boxes.

## Labor

- Low voltage technician: 1 hour per station at $78.00 per hour.
- Apprentice: 0.5 hours per station at $38.00 per hour.
