# Code Reference for Radiation-Hardened Fiber Optic Trunk in FL

This code reference applies to radiation-hardened fiber optic trunk installations in Kennedy Space Center, FL. It summarizes the governing requirements for estimating and installation. Synthetic summary for testing only.

## Governing Codes

Code requirements covered: vacuum rated, radiation hardened. FL code reference.

- MIL-STD-1553 and NASA-STD-8739.4 cable and harness requirements
- IEC 60793 optical fiber specifications

## Requirements

- Fiber trunk components exposed to vacuum must be vacuum rated and outgassing tested to ASTM E595.
- Radiation hardened fiber is required where total ionizing dose exceeds 10 krad over service life.
- Every splice must be recorded with an OTDR trace and stored with the telemetry commissioning package.
- Minimum bend radius is 20 times the cable diameter under load.
- Hermetic feedthroughs must be leak tested to 1e-8 std cc/sec helium.
- Transceiver optical power budget must retain 3 dB margin after radiation aging.

## Labor Guidance

- Work must be performed by a licensed contractor with a permit and final inspection.
- Inspection and documentation time should be estimated at 5 percent of installation labor.
