# Code Reference for Residential Rooftop Solar in CA

This code reference applies to residential rooftop solar installations in San Diego, CA. It summarizes the governing requirements for estimating and installation. Synthetic summary for testing only.

## Governing Codes

Code requirements covered: NEC Article 690, utility interconnection. CA code reference.

- NEC Article 690 Solar Photovoltaic Systems
- California Rule 21 utility interconnection

## Requirements

- NEC Article 690.12 requires rapid shutdown of the rooftop array to 30 V within 30 seconds.
- Utility interconnection under Rule 21 requires an approved application before the system is energized and a lockable AC disconnect accessible to the utility.
- Roof flashing is required at every racking attachment on composition shingle roofs.
- PV wire must be listed for wet locations and sunlight exposure and secured every 4.5 feet.
- A 3 foot setback from the ridge and pathways to the ridge are required by the California Fire Code.
- The string inverter must be listed to UL 1741 SB for the CA grid support functions.
