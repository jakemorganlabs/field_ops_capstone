# Code Reference for Addressable Fire Alarm Devices in NV

This code reference applies to addressable fire alarm devices installations in Las Vegas, NV. It summarizes the governing requirements for estimating and installation. Synthetic summary for testing only.

## Governing Codes

Code requirements covered: NFPA 72, ADA visible notification. NV code reference.

- NFPA 72 National Fire Alarm and Signaling Code
- NEC Article 760 Fire Alarm Systems

## Requirements

- NFPA 72 requires a manual pull station within 5 feet of each exit door and no more than 200 feet travel distance between stations.
- ADA visible notification requires horn/strobe devices in every public and common area with candela ratings per NFPA 72 Chapter 18.
- Addressable smoke detector spacing must not exceed 30 feet on smooth ceilings.
- Fire alarm cable must be FPLR or better and installed separate from power circuits per NEC Article 760.
- The control panel must have 24 hours of standby battery plus 5 minutes of alarm.
- A 100 percent acceptance test with a record of completion is required before the system is placed in service.
