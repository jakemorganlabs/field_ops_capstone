# Code Reference for Cat6A Structured Cabling Plant in PA

This code reference applies to cat6a structured cabling plant installations in Philadelphia, PA. It summarizes the governing requirements for estimating and installation. Synthetic summary for testing only.

## Governing Codes

Code requirements covered: TIA-568 standards, plenum rated. PA code reference.

- TIA-568 standards: ANSI/TIA-568.2-D balanced twisted-pair cabling
- NEC Article 800 Communications Circuits

## Requirements

- TIA-568 standards limit the permanent link to 90 meters with 10 meters total for patch cords.
- Plenum rated cable (CMP) is required in air handling spaces per NEC Article 800.
- Every Cat6A link must be certified with a field tester to TIA-568.2-D Category 6A limits and the results delivered to the owner.
- Maximum cable bundle size is 24 cables to limit alien crosstalk.
- Patch panels and equipment racks must be bonded to the telecommunications grounding busbar.
- Labels are required on both ends of every cable and on every patch panel port per TIA-606.
