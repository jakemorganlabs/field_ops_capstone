# Code Reference for Card Access Control Doors in IL

This code reference applies to card access control doors installations in Chicago, IL. It summarizes the governing requirements for estimating and installation. Synthetic summary for testing only.

## Governing Codes

Code requirements covered: NFPA 101 egress, ADA compliance. IL code reference.

- NFPA 101 Life Safety Code Chapter 7 Means of Egress
- 2010 ADA Standards for Accessible Design Section 404 Doors

## Requirements

- NFPA 101 egress requires that every controlled door allow free egress at all times; the electrified strike must release on fire alarm and on power loss where the door is in an egress path.
- ADA compliance requires door hardware operable with one hand without tight grasping and card readers mounted between 34 and 48 inches above the floor.
- A request-to-exit sensor and a door position sensor are required at every access controlled door.
- The access control panel must be on standby power for at least 4 hours.
- Delayed egress locks, where used, must release within 15 seconds of a 3 second push.
- All access events must be logged with a timestamp and retained for 90 days.
