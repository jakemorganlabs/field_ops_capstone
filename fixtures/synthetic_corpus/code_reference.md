# Low-Voltage Code Reference for CA

This code reference applies to low-voltage data cabling installations in commercial buildings in CA region.

## Requirements

- All Cat6A cable must be plenum rated when installed in plenum spaces.
- Maximum cable bundle size is 50 cables when supported by J-hooks.
- Cables must be supported every 5 feet when run horizontally.
- Penetrations through fire-rated assemblies require firestopping.
- Labels are required on both ends of every cable.
- Patch panels must be grounded per manufacturer instructions.

## Labor Guidance

- A single electrician and one apprentice are required per drop.
- Estimated labor per drop is 2 hours total.
