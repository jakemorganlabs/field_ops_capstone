# Code Reference for In-Row Cooling and Containment in VA

This code reference applies to in-row cooling and containment installations in Ashburn, VA. It summarizes the governing requirements for estimating and installation. Synthetic summary for testing only.

## Governing Codes

Code requirements covered: ASHRAE thermal guidelines, hot aisle containment. VA code reference.

- ASHRAE TC 9.9 Thermal Guidelines for Data Processing Environments
- ASHRAE 90.4 Energy Standard for Data Centers

## Requirements

- The ASHRAE thermal guidelines recommended envelope is 64.4 to 80.6 degrees F at the rack inlet with dew point between 41.9 and 59 degrees F.
- Hot aisle containment requires containment doors at both aisle ends and roof panels above every rack; gaps larger than 1 inch must be sealed.
- One temperature sensor per rack at the inlet is required to verify the envelope.
- In-row air conditioner condensate must drain to an approved receptor with an overflow alarm.
- Blanking panels are required in all open rack units to prevent recirculation.
- Chilled water connections need isolation valves and leak detection at each unit.
