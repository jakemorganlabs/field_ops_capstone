## One-liner

Turns field-service job intake into grounded, source-cited proposals using a pgvector RAG layer over a cabling-spec corpus, an estimator/writer/reviewer agent loop, deterministic cost calculators, and a mandatory human approval gate.

## Tech stack

TypeScript, Node 22, Postgres + pgvector, DeepInfra LLMs, GitHub Actions, SLSA build provenance attestations.
